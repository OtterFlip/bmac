# HTTPS endpoints that egress_health.py rotates through to check a mox host's
# internet connection: one HEAD request every 5 seconds, each to the next
# target, so each sees about one request every few minutes from each host.
# Any HTTP response counts as success. Host setup and the "Sync cluster with
# cluster.conf" operation keep only the targets that answer; a target that
# keeps failing while the others answer is retired. Spread across many
# operators so no single outage looks like a dead connection.
